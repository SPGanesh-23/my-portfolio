Mobile app · Smart attendance

Blue_Mark

A BLE-based smart attendance system for classrooms. The teacher's phone becomes a Bluetooth Low Energy beacon — students nearby are detected automatically, so attendance is only marked when they're physically present.

React Native · ExpoBluetooth LENode.js + ExpressPostgreSQL · PrismaReact Dashboard
View on GitHub ↗

📍 Try it: BLE proximity check

How Blue_Mark decides if you're in the room. Move closer to or further from the teacher's beacon and watch the signal — attendance marks only when the signal is strong enough.

✓ Attendance marked — you're in range

Signal is strong enough to confirm you're physically in the classroom. The backend would now validate the time window, check for duplicates and confirm enrolment before saving the record.

Signal strength (RSSI): −68 dBm · Threshold −75 dBm
